# 商智通 · 企业 AI 经营增长助手（演示版）

面向成长型企业的 AI 经营增长 SaaS：把企业真实的产品、价格与资料，变成可复用的营销内容和可溯源的知识库问答。企业端与平台管理端共用一个数据层，AI 生成由内置规则引擎完成，**不需要任何 API Key 即可体验完整流程**。

## 快速开始

```bash
npm install
npm run dev
# 打开 http://localhost:3000
```

重置演示数据（新增/修改的数据会被清空，自动恢复种子数据）：

```bash
npm run seed
```

生产构建：

```bash
npm run build && npm start
```

## 部署到服务器

Linux 服务器（宝塔面板 + Docker）部署步骤见 [DEPLOY.md](./DEPLOY.md)。

## 已实现功能

### 企业端 `/app`

- 工作台：真实客户指标、待办、最近生成、额度与资料完善度
- AI 营销：文案（2 个候选版本）、短视频分镜脚本、活动策划，均注入本企业品牌与产品资料
- 生成历史：保存输入、结果、模型与 token 用量，支持类型筛选与删除
- 品牌资料：企业介绍、目标客户、语气、核心优势、禁用表达（角色可写控制）
- 知识库：文档上传/解析/删除、产品与服务 CRUD、带来源引用的 AI 问答
- 客户管理：搜索筛选、标签、跟进记录、下次跟进待办、CSV 导出（带权限与审计）
- 数据分析：新增趋势、来源/标签分布、跟进完成率、AI 用量与估算成本
- 系统设置：企业信息、成员列表与邀请、套餐额度、反馈工单、退出登录

### 平台管理端 `/admin`

- 总览：企业客户、客户数、AI 用量、成本、工单、最近审计
- 企业客户：搜索、新增（同时创建订阅+负责人）、详情、状态启停、套餐/额度调整
- 用户管理：用户与成员关系、角色与账号状态
- 套餐管理：新增/编辑价格、额度、权益、有效期与启停
- 订阅/订单：到期提醒、人工收款状态
- AI 模型：模型网关配置说明与启用状态
- AI 用量：按企业/类型/时间汇总，Token、成本、失败率
- 模板管理：提示词模板版本展示
- 反馈工单：回复与状态流转，企业端同步可见
- 审计日志：管理员敏感操作全量记录
- 平台设置：公告、安全配置与上线检查清单

## 技术结构

```
src/
  app/
    (merchant)/app/...      企业端路由
    (platform)/admin/...    平台端路由（独立布局与导航）
    login/                  登录（演示会话）
    api/logout              退出
    api/merchant/customers/export  CSV 导出（权限 + 审计）
  components/               Shell、UI、生成表单、聊天等
  lib/
    types.ts                数据模型
    seed.ts                 演示种子数据
    store.ts                文件数据库（读改写 + 串行化 + 版本化重建）
    session.ts              会话、租户上下文、角色权限
    generator.ts            AI 生成/检索/防幻觉规则引擎（sz-ai-pro）
    actions.ts              Server Actions（全部写操作）
public/brand/               商智通商标素材（图标 / 横版 / 全版）
data/db.json                运行时演示数据库（已 gitignore）
```

### 架构要点

- 双端共用数据层：企业端与平台端读取同一份 `data/db.json`，平台改套餐后企业端上下文立即变化。
- 多租户隔离：所有业务读取都以服务端会话解析出的 `tenant_id` 过滤，请求参数不能指定租户；目前由服务端强制过滤实现，接入 Supabase 后替换为 RLS。
- 角色权限：企业管理员 / 部门主管 / 员工 / 平台管理员分别控制写操作、导出、成员邀请与平台接口，前端隐藏菜单不作为权限依据。
- AI 网关：所有生成经服务端 `generateMarketing`，生成前检查租户状态与额度，生成后写 generation + usage log。
- 防幻觉：知识库问答无匹配时明确返回“资料不足”，不编造价格与服务范围。
- 敏感信息：客户手机号脱敏展示；导出记录审计；AI 密钥只从服务端环境变量读取（正式版）。

## 从演示版接入正式环境

1. **数据库**：按 `docs` 中的表清单在 Supabase 建表（tenants、tenant_memberships、brand_profiles、dishes、marketing_generations、usage_logs 等），启用 RLS。
2. **认证**：用 Supabase Auth 替换 `src/lib/session.ts` 的演示 Cookie，实现邀请/重置密码。
3. **数据访问**：将 `src/lib/store.ts` 的 `getDb / mutateDb` 替换为 Supabase 查询与服务端 repository；页面与 Server Actions 的租户过滤逻辑保持不变。
4. **AI**：在 `src/lib/generator.ts` 中保留 prompt 组装与输出 schema，把规则引擎替换为 Model Gateway 调用；密钥只放服务端 `.env`。
5. **文件**：上传改为 Supabase Storage 私有 Bucket + 解析任务；`knowledge_files / knowledge_chunks` 带 tenant_id。
6. **上线**：补齐隐私政策、用户协议、备份恢复演练与验收清单。

## 说明

- 演示数据中的企业、客户、产品与经营数据均为虚构。
- AI 输出由规则引擎生成，用于展示产品流程与页面效果；正式接入模型后输出质量与格式由真实模型决定。
- 商标与品牌名（商智通）来自赛方提供的企业素材，页面仅用于本演示。
